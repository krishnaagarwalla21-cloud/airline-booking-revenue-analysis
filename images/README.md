
# Project Visualisations

This folder contains charts generated during the Airline Booking & Revenue Analytics project.

- `monthly_booking_trend.png` — Monthly booking counts from September 2020 to December 2025.
- `payment_methods_analysis.png` — Distribution of payment records by payment method.
- `refund_reasons_analysis.png` — Distribution of refund records by recorded reason.

The visualisations describe a synthetic airline dataset, not actual airline industry performance.
